# Sputnik · спутниковые данные для геологии

Десктопный веб-интерфейс GeologyScience. Каталог продуктов с фильтром по геологическому применению, выбор региона и дат, обзор сцены и скачивание файлов у поставщика. Для прямоугольной области можно использовать карту, её текущий вид или координаты в WGS 84. Готовые регионы задают ориентировочные прямоугольники.

## Запуск

Выполните в корне репозитория. Скопируйте `example.env` в `.env`, затем задайте в `.env` нужный порт на хосте через `SPUTNIK_PORT`.

```powershell
Copy-Item example.env .env
docker compose up --build -d
```

На Linux и macOS для копирования используйте `cp example.env .env`. При настройках из примера сервис откроется по [http://127.0.0.1:18080](http://127.0.0.1:18080). После изменения `.env` примените настройки командой `docker compose up -d`.

Для reverse proxy, работающего непосредственно на хосте, подходит `SPUTNIK_BIND_HOST=127.0.0.1`. Если хостинг требует прямого доступа к опубликованному порту, укажите `SPUTNIK_BIND_HOST=0.0.0.0`. Внутренний порт контейнера — `8080`.

Состояние сервиса показывает `docker compose ps`, журнал — `docker compose logs -f sputnik`. Для остановки выполните `docker compose down`. Для сборки нужен доступ к Docker Hub, npm и PyPI. При работе контейнер обращается к Microsoft Planetary Computer. Браузер получает подложку OpenStreetMap, предпросмотр и спутниковые файлы непосредственно от поставщиков.

Пример для проверки поиска. Выбрать Sentinel‑2 MSI и «Своя область», ввести запад `132`, юг `43`, восток `133`, север `44`, период с `2025-08-01` по `2025-08-31`. Открыть одну из записей и скачать, например, красный канал `B04`. Облачность в выдаче относится ко всей сцене. Даты в выдаче показаны по UTC.

## Как устроено

- `catalog.py` задаёт поддерживаемые коллекции, геологические теги и пояснения. Один продукт может иметь несколько тегов.
- `app.py` обращается к STAC API. Для Sentinel‑5P ограничивает запрос продуктом SO₂. Для Copernicus DEM выполняет поиск плиток по территории.
- Файлы запрашиваются по идентификатору сцены и ключу ресурса. Python получает короткоживущую SAS-ссылку на Azure Blob, после чего браузер получает файл напрямую.
- Размер файла берётся из STAC или уточняется запросом `HEAD` к хранилищу. Геопривязанное превью использует тайлы поставщика.
- Состояние запроса находится в открытой вкладке. Контейнер не требует базы данных, постоянного тома, аккаунта Microsoft или ключей доступа.

Проверяемые сведения о продуктах доступны в карточках каталога. Для продуктов без готового изображения, в том числе SO₂, доступны контур наблюдения, метаданные и файлы при наличии ссылки от поставщика. Прямой доступ к OpenStreetMap использует атрибуцию и обычное интерактивное получение тайлов. [Политика использования тайлов OSM](https://operations.osmfoundation.org/policies/tiles/)
